Design system based on techspirit.barcelona

Two sizes. One edge. Light by dimming.

Overview

This design system uses HTML, Tailwind CSS v4 (CDN) and Lucide icons. Its design language comes from techspirit.barcelona. Each component has a short semantic class. All classes use @apply in one <style type="text/tailwindcss"> block. The system does not use clamp() or custom font sizes. It uses only the Tailwind scale with breakpoints.

  1. 01Two sizes.The display size is large: Inter Tight, tracking −0.035em, line height 1.02. The text size is small: Geist, 14px. Use the mid size only for card titles. Make hierarchy with size and space. Do not use bold weights for hierarchy.
  2. 02One text edge.All text starts on one vertical line (.col). Numbers, icons and marks hang to the left of this line, in the hang margin. They do not move the text.
  3. 03Mono + six signals.The base is black and white. Six accent colors go from orange to blue. Use an accent only to show meaning: a category, a company or a track.
  4. 04Focus by dimming.When you point at one item, the other items dim to 28–30%. Photos are black and white until you point at them. Buttons and bands invert the colors.
  5. 05Hairlines, not boxes.A 1px line above each section and card separates them. Do not use shadows or card fills. Use round corners only on photos, pills and capsules.

Tokens

The @theme block declares the tokens. The theme colors (bg, fg, tile, rule) are in @theme inline. They point to CSS variables. Thus one data-theme attribute on <html> changes the theme. Opacity modifiers such as text-fg/45 and border-fg/20 also work.

Typography

The system has two fonts and two sizes. Use Display (Inter Tight, in place of Favorit) only for the large size. Use Geist for all small text. .sup is a small note. It hangs from the cap line of a large word. Use it for track numbers and timer units.

Lineup — «The Lineup Is Taking Shape»

      
This is the main pattern for cases and services. On desktop, it is one paragraph of large display text. Each item has a media pill, a name and a sub-label. A « / » separates the items. The media (face, thumbnail or icon) sits in the line like a letter. It is 0.74em high and 1.12em wide, fully round, and black and white. An accent color shows the sub-label (company or category). On hover or focus, the other items dim to 28%. The photo gets its color. A preview card (200px, rounded-2xl, tile) moves with the pointer. On phones, the paragraph becomes a list. Each row has a top line, 64×80 media on the left, and the name and sub-label on two lines. A tap shows the card at the bottom of the screen. A second tap on a link opens it. The card gets its data from data-img | data-icon, data-title, data-sub, data-text and data-meta. Put an empty .lineup-card next to the list.

States
.lineup.is-active: one item has focus. All items go to 28%.
.lineup-item.is-on: the active item. It is at 100%, its photo has color, and its icon inverts.
.lineup-card.is-on: the card is visible.

        
How the parts work together
One display size, one accent color for the sub-label, and media that acts like a letter. The « / » separators at 25% give rhythm without lines. The list dims other items. It does not highlight the active item. Tracks and the menu use the same method.

        
Accessibility
The script adds tabindex="0" to items that are not links. Focus shows the card next to the item. The card has aria-hidden because it repeats the data. prefers-reduced-motion stops the transitions.

      

    

    

      
Tracks (accordion)

      
This is a large list. A click opens an item. Hover does not open it. Hover only wakes the line: the other lines dim to 30%. The mark hangs in the hang margin. (On the original site, the mark is an animated orb.) The item opens with a grid-template-rows: 0fr → 1fr animation. The script does not measure the height. With data-single, only one item can be open. Use this list for a process or a detailed list of services.

Drawer

      
On desktop, the drawer opens from the right (640px). On phones, it opens from the bottom as a sheet with a grab bar. The scrim is at 55%. To close the drawer, click outside it, click Close or push Esc. The slide takes 450ms with ease-expo.
